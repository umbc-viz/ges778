Working with historic shapefiles

Author

Camille Seaberry

Modified

November 24, 2026

Here are a couple quick examples of working with shapefiles that give historic context to your maps.

HOLC redlining maps

First, the infamous HOLC redlining maps digitized and released by Nelson & Winling (2023). The data is available for download for every city included, or for specific cities. I’ll read the shapefile directly for Baltimore. It even includes hex codes for the colors to use on each shape, and labels for each neighborhood to help you link back to the description cards, which you can download as well (makes a good little text mining project).

Nelson, R. K., & Winling, L. (2023). Mapping Inequality: Redlining in New Deal America. In American Panorama: An Atlas of United States History. https://dsl.richmond.edu/panorama/redlining/; University of Richmond Digital Scholarship Lab. 
library(ggplot2)

  theme_minimal() +

      plot.title.position = "plot",

# extract assigned colors into a named vector
holc_pal <- holc |>
  dplyr::select(grade, fill) |>
  sf::st_drop_geometry() |>
  dplyr::distinct() |>
  dplyr::filter(!is.na(grade)) |>
  tibble::deframe()

# those colors are pretty washed out, here's what I used for my article
holc_pal2 <- setNames(
  c('#25da44', '#3F88E7', '#ded02c', '#E73F54'),
  c("A", "B", "C", "D")
)

Now with vacants superimposed. There are more than 11,000 vacants in this data, and we’ve already worked with some methods of dealing with the overplotting. Here’s one more: the DBSCAN algorithm for finding clusters of observations, via the sfhotspot package.

# keeping default args, which test parameters for me
set.seed(24)
vacant_clusters <- sfhotspot::hotspot_dbscan(justviz::vacants_sf)

ggplot() +
  geom_sf(aes(fill = n), data = vacant_clusters, alpha = 0.7) +
  scale_fill_fermenter(palette = "Greys", direction = 1)

However, I don’t think this is going to give me something easy to read to put on top of a colored map. Instead, I’ll take the centroids of those cluster polygons and place a bubble at each one.

vacant_cents <- sf::st_centroid(vacant_clusters)

ggplot() +
  geom_sf(aes(size = n), data = vacant_cents, alpha = 0.7) +
  scale_size_area(max_size = 14)

Putting it all together:

counties_sf <- tigris::counties(state = "MD", cb = TRUE, progress = FALSE) |>
  dplyr::select(name = NAMELSAD)
balt_sf <- counties_sf |> dplyr::filter(name == "Baltimore city")

# I stashed the data download date as an attribute
updated <- attr(justviz::vacants_sf, "last_updated") |>
  lubridate::ymd() |>
  format("%b %e, %Y")

ggplot() +
  geom_sf(
    aes(fill = grade),
    data = holc |> dplyr::filter(!is.na(grade)),
    color = "gray40",
    linewidth = 0.2,
    alpha = 0.8
  ) +
  geom_sf(data = balt_sf, color = "gray10", linewidth = 0.5, fill = NA) +
  geom_sf(aes(size = n), data = vacant_cents, alpha = 0.7, color = "gray20") +
  scale_size_area(
    max_size = 14,
    labels = scales::label_number(big.mark = ",")
  ) +
  scale_fill_manual(values = holc_pal2, na.value = "gray95") +
  coord_sf(ndiscr = 0) +
  labs(
    title = "Baltimore vacant building hotspots, with 1937 historic HOLC 'redlining' grades shown",
    subtitle = paste("Vacant building notices current as of", updated),
    size = "Vacants in hotspot",
    fill = "HOLC grade",
    caption = "Sources:\nOpen Data Baltimore portal, Vacant Building Notices\nUniversity of Richmond Digital Scholarship Lab, Mapping Inequality"
  )

Native Land data

The Native Land project makes their data available for download, but it requires a free API key. They don’t have a simple place to download; you’ll need to use their API but it’s well documented. There’s an endpoint for getting data by coordinate, and another for getting data within a bounding box. I’ll use the latter, for territories that intersect with Maryland (intersection doesn’t actually seem to work…?).

# returns a matrix with named columns
md_geojson <- counties_sf |>
  sf::st_union() |>
  sf::st_transform(4326) |>
  rmapshaper::ms_simplify() |>
  geojsonio::geojson_json()

# save locally
nl_path <- here::here("extras/native_land_balt.json")
# this is supposed to just include areas that intersect with the polygon I supply
# instead it seems to return everything, so I'll filter
httr2::request("https://native-land.ca/api/index.php") |>
  httr2::req_url_query(
    maps = "territories",
    polygon_geojson = as.character(md_geojson),
    key = Sys.getenv("NATIVE_LAND_KEY")
  ) |>
  # httr2::req_method("POST") |>
  httr2::req_perform(verbosity = 0) |>
  # gets written into improper format---need to drop one level of list hierarchy
  # manually remove first and last square brackets
  httr2::resp_body_string() |>
  stringr::str_remove_all("(^\\[|\\]$)") |>
  writeLines(nl_path)
native <- sf::st_read(nl_path, crs = 4326)

md_native <- native |>
  sf::st_make_valid() |>
  dplyr::filter(sf::st_is_valid(geometry)) |>
  sf::st_transform(sf::st_crs(counties_sf)) |>
  sf::st_filter(counties_sf)

# get a bounding box a few miles bigger than state
md_bbox <- counties_sf |>
  sf::st_union() |>
  sf::st_transform(2248) |>
  sf::st_buffer(dist = 5280 * 5) |>
  sf::st_transform(4269) |>
  sf::st_bbox() |>
  sf::st_as_sfc()

native_to_map <- md_native |>
  sf::st_intersection(md_bbox) |>
  # clean names by keeping what's in parentheses if it has them
  dplyr::mutate(
    Name = ifelse(
      grepl("\\(", Name),
      stringr::str_extract(Name, "(?<=\\()(.+)(?=\\))"),
      Name
    )
  )

native_cents <- native_to_map |>
  sf::st_centroid() |>
  dplyr::mutate(coords = sf::st_coordinates(geometry)) |>
  dplyr::mutate(x = coords[, "X"], y = coords[, "Y"]) |>
  sf::st_drop_geometry()

ggplot() +
  # comes with color column
  geom_sf(aes(fill = color), data = native_to_map, alpha = 0.2) +
  geom_sf(data = counties_sf, fill = NA, color = "gray10", linewidth = 0.2) +
  ggrepel::geom_label_repel(
    aes(label = Name, x = x, y = y, color = color),
    data = native_cents,
    seed = 24,
    fontface = "bold"
  ) +
  scale_fill_identity() +
  scale_color_identity() +
  coord_sf(ndiscr = 0) +
  labs(
    title = "Native territories of the Maryland area",
    caption = "Source: Native Land Digital via API",
    x = NULL,
    y = NULL
  )

Definitely could do more to place the labels, such as placing them at the nearest point to the bounding box or a convex hull.
